# Yapuno

**Your crew. Your chat.**

Yapuno is a proposed privacy-conscious, parent-approved messaging space for children and teens. This public repository is an early-stage project; **no production-ready child-safety guarantees exist yet**.

The first goal is a passwordless, closed-contact text chat across iOS and Android over an internet connection, without a phone number.

Design and contribution guidance will be added through reviewed pull requests. This repository is public, but until a license is selected, public visibility alone does not grant reuse rights.
