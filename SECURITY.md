# Security policy

Yapuno is a **prototype**. Do not deploy for children or rely on it for child protection.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** / private vulnerability reporting feature if enabled for this repository. If unavailable, contact the repository owner through a private channel; do **not** publish working exploit details, credentials, child information or identifying examples in public issues.

Include the affected component, the impact and a minimal reproduction with synthetic data only. We will coordinate a fix and disclosure rather than promise a fixed response SLA.

## Security priorities

Isolation across tenants and families; mutual guardian approvals; device registration and revocation; websocket and notification authorization; secure message storage and retention; abuse reporting without indiscriminate surveillance.

No bug bounty programme or certification is offered at this stage.
